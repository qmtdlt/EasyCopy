# 前端验证

## 自动验证

- `npm test`：9 项真实事件动画状态测试，包括首帧 300ms、140ms 淡出、长任务完成直接淡出、准备/校验不制造进度、失败状态、任务隔离、减少动态效果和销毁回调。
- `npm run build`：Vue/TypeScript 类型检查及 Vite 生产构建。
- 浏览器验证还覆盖自启动默认无写入、开启/关闭、注册失败回读、系统状态刷新、读取失败重试、调试版限制及最小窗口宽度。它使用模拟接口，不改系统登录项；可设置 `QA_OUTPUT` 指定截图与报告目录。
- 先运行 `npm run dev`，再运行 `node tests/browser-qa.mjs`：独立无头 Chrome，1000 × 700 视口，通过测试专用的模拟 Tauri 接口验证历史分类、悬停按钮、复制调用、设置保留已保存密钥、上传/下载镜像填充、失败显示与隐藏回调。可用 `CHROME_PATH` 指定 Chromium 可执行文件，用 `QA_URL` 指定开发服务器。

- 文件确认验证：文件行仅有“另存为”；询问默认焦点为“否”，回车、Esc、关闭均拒绝，明确点击“是”才同意；阈值可保存为 10、100 或其他正整数，并显示保存失败。仍为模拟接口，不操作实际剪贴板。

## 截图

`artifacts/` 中的历史与设置截图含明确的“界面测试 · 模拟数据”标记，内容仅为布局验收样本。模拟接口只在测试浏览器注入，生产客户端没有示例历史、伪连接或模拟传输。

这些测试没有验证原生剪贴板、真实网络、NSWindow / Windows 悬浮窗口、多显示器、DPI 或实际系统焦点。上述内容由桌面与跨设备联调记录覆盖。
