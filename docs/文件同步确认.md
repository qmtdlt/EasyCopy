# 文件同步确认

更新日期：2026-11-04。

## 已确认行为

- 历史中的文本、图片仍可复制并重新同步；文件和文件夹仅可另存为，后端也拒绝历史文件复制。
- 本机复制文件时，汇总本次所选文件和文件夹内部普通文件的原始大小，严格超过阈值才询问上传。图片文件属于文件，剪贴板图片内容不受此限制。
- 设置页“文件上传确认”可修改阈值，单位 MB（1,000,000 字节），默认 50，支持正整数。单独保存，不需要修改服务器配置或重连；重启后保留，旧配置自动使用 50。
- 保存后从下一次复制生效，已弹出的询问继续显示并使用本次复制时的阈值。
- 默认焦点在“否”。回车、Esc、弹窗关闭按钮、主窗口关闭都拒绝。只有明确选择“是，上传”才放行。
- 等待确认和拒绝的内容不建立历史记录、不登记服务器任务、不打包，因此没有可重连重试或重启恢复的发送任务；本机剪贴板不变，仍可粘贴。
- 同一原生剪贴板序号只处理一次。复制新内容会撤销旧询问，旧答复不能授权新内容；主动重新复制相同文件会重新判断。
- 远端接收仍由原有序号机制抑制自身写入，不弹上传询问。另存后在文件管理器主动复制文件，仍是新的本地复制操作。
- 初次统计未超阈值、打包前文件却增大超过阈值时中止，提示重新复制确认。读取大小失败或遇到不支持的链接/特殊文件不放行。

## 实现位置

- `crates/client-core/src/upload_confirmation.rs`：异步大小统计、临时确认状态、阈值持久化、答复验证；与监听及远端写回共用串行锁。
- `crates/client-core/src/sync.rs`、`lib.rs`、`archive.rs`：捕获入口、文件历史复制限制、准备时再次检查大小。
- `apps/desktop/src/components/FileUploadConfirmation.vue`：模态询问、默认焦点、拒绝操作。
- `apps/desktop/src/components/FileUploadSetting.vue`：独立阈值设置。
- `apps/desktop/src-tauri/src/lib.rs`：命令与事件桥接，询问时显示主窗口，关闭主窗口时拒绝。
