# 首版实现接口（公共文件由主代理维护）

协议权威定义：`crates/protocol/src/lib.rs`，JSON 使用 snake_case。UI 与 Tauri 命令参数/结果使用 camelCase。

## 服务

所有接口要求 `Authorization: Bearer <secret>`。HTTPS 逻辑名来自可信配对串，物理地址为用户填写 IP/端口。上传在准备完成后提供 `x-easycopy-size` 与 `x-easycopy-sha256`，服务端按流实际接收广播 Progress，全部写入/校验后 Completed。幂等登记固定 id/device/kind/preview，重复相同请求返回同一记录，不同内容冲突。Failed 允许同 id 从头上传（重试），Complete 必须直接返回现有状态。取消未完成任务保持墓碑。WS 订阅与历史快照在同一锁内创建，快照 high_water 为所有已登记意图的最高 sequence；订阅溢出发 ResyncRequired 并断开。

## 客户端 Rust 公共接口

`ClientCore::open(data_dir: PathBuf) -> anyhow::Result<Arc<ClientCore>>`

- `async fn start(self: &Arc<Self>)`
- `fn subscribe(&self) -> tokio::sync::broadcast::Receiver<ClientEvent>`
- `fn history(&self) -> Vec<HistoryEntry>`
- `fn settings(&self) -> PublicSettings`
- `async fn test_connection(&self, input: SettingsInput) -> Result<ServerInfo>`
- `async fn save_settings(self: &Arc<Self>, input: SettingsInput) -> Result<()>`
- `async fn copy_item(self: &Arc<Self>, id: Uuid) -> Result<()>`
- `async fn save_item(&self, id: Uuid, destination: PathBuf) -> Result<()>`（文本/图片目标为文件；files 目标为目录，禁止覆盖已有用户文件）
- `fn shutdown(&self)`

需变更接口先通知主代理。尽量提供 headless mock clipboard 测试构造器以供多客户端端到端集成测试，避免测试抢占真实剪贴板。

`HistoryEntry { available: bool, id: Uuid, kind: ContentKind, device_name: String, created_at: i64 (Unix毫秒), sequence: Option<u64>, preview: String, detail: String, thumbnail: Option<String> (small PNG data URL), status: String, error: Option<String> }` 序列化 camelCase。available 表示本地完整内容可复制/保存，与同步成功与否分开。

`SettingsInput { address: String, port: u16, pairing_key: String }`（空 pairing_key 保留已保存密钥）
`PublicSettings { address: String, port: u16, has_pairing_key: bool }`（不回传 secret）
`ClientEvent` 内部变体：`HistoryChanged`, `Connection { connected: bool, message: String }`, `Transfer(TransferEvent)`。
`TransferEvent { task_id: String, direction: String (upload/download), phase: String (start/preparing/transferring/verifying/complete/failed), received_bytes: u64, total_bytes: Option<u64>, error: Option<String> }` 序列化 camelCase。

## 前端/Tauri

invoke 命令：`list_history -> HistoryEntry[]`、`get_settings -> PublicSettings`、`get_connection -> {connected,message}`、`test_connection({input:SettingsInput}) -> ServerInfo`、`save_settings({input:SettingsInput}) -> void`、`copy_item({id:string})`、`save_item({id:string})`（原生保存/选目录对话框由主代理实现）、`overlay_ready()`、`overlay_hidden({taskId:string})`。

事件：`history-changed` payload 为 HistoryEntry[]，`connection-changed` 为 `{connected,message}`，`transfer` 为 TransferEvent。

`?overlay=1` 渲染透明悬浮层。前端启动监听后 invoke overlay_ready；后台 start 时定位/显示且不激活，前端首帧计时≥300ms，140ms淡出，结束 invoke overlay_hidden（后端检查 task id）。前端必须支持早于 ready 的事件重发。仅调试浏览器可以出现明确的“浏览器预览”状态，不伪装服务器已连接。
