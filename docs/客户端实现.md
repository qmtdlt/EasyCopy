# 客户端实现

客户端核心位于 `crates/client-core`，UI/Tauri 通过 `ClientCore` 订阅历史、连接及传输事件。原生读写位于 `clipboard/macos.rs` 和 `clipboard/windows.rs`。

## 内容与系统剪贴板

- macOS 使用 NSPasteboard.changeCount，文件引用 `public.file-url` 优先于 PNG/TIFF 与 UTF-8 文本；写回文件是真实本机缓存 URL，图片写 PNG。
- Windows 创建 message-only 窗口监听 WM_CLIPBOARDUPDATE，并使用 GetClipboardSequenceNumber 校验版本；文件 CF_HDROP 优先于注册 PNG/DIBV5/DIB 与 Unicode 文本。写 PNG 同时提供带 alpha mask 的 DIBV5；文件写 UTF-16 DROPFILES，不设置移动语义。
- 原生变化序号和自身写入后的实际序号一致时不重复登记。读取失败不消耗变化序号。远端写入前再次比较原生序号，不使用禁读时间窗口。
- Windows 写入先关闭剪贴板，再重新打开并核对 owner 后取得最终序号；系统补充格式可能使关闭后的序号继续变化。如果关闭期间其他 owner 写入，保留旧写入序号，让监听器继续捕获新的外部内容，不把它误认为自身写入。
- NativeClipboard 测试默认为 ignored，手动执行会改真实剪贴板，只能保留和恢复本产品支持的公开格式。不能据此声称已保真保留其他应用的私有格式。

## 顺序和重连

本机复制先创建持久捕获记录，再由单独队列按捕获顺序向服务端登记；获得 sequence 后才生成传输 payload。文件的捕获只保存本机路径，原始文本/PNG 持久暂存到受保护缓存。准备和传输并行，完成时间不改变历史位置。断电重启可从捕获恢复已登记的准备任务；源文件消失或变化会明确失败。

接收时同时校验事件 sequence、首次 Registered 的本机复制代数、连接 epoch、WS 快照 high_water、在途本地登记，以及实际原生剪贴板序号。迟到内容完成校验后可以补历史，但不能覆盖更新复制。首次快照与重连快照只补历史，快照中尚未完成的旧任务之后完成同样不会自动覆盖。

是否允许上传在捕获当时固定：离线复制只留本机；之后连接恢复也不自动登记它。每条同步记录绑定 server_id，修改配对服务器不会将旧任务内容发送给新身份。点击历史复制创建全新事件身份与顺序。

## 传输与安全

Transport 的 HTTPS/WSS 都只信任配对串 CA，使用稳定逻辑服务器名称完成标准链、主机名和有效期验证，实际 TCP 映射到输入地址。HTTP 禁代理、禁止重定向。密钥写系统 keyring，settings.json 不含密钥。启动构造函数不访问系统凭据；keyring 读写在后台 blocking 线程执行。系统授权对话框等待或拒绝时，窗口、本地剪贴板和历史继续工作，连接状态说明原因。读取结果按独立设置代数检查，迟到的旧凭据不会覆盖用户随后保存的配置。自身 `easycopy1:` 配对文本（trim 后前缀匹配，包括无效或截断内容）不会进入历史、捕获缓存或同步队列；用户显式复制此类历史内容会收到说明。此规则不尝试识别其他密码。headless MemoryClipboard 构造器专供测试，配对信息仅存在内存。

上传从文件流读取，不把大文件读入内存。HTTP upload 不设固定总时长；普通控制接口有短超时，下载逐块等待有超时。上传进度只转发服务器实际接收字节；下载进度按已接收并写入的块累计。提交前后均检查 SHA-256 与总长度。初次尝试之外最多 3 次自动重试，上传先查询原 ID 状态，避免响应丢失后重复发布；下载重试预算随记录持久化。

TAR 只允许普通文件和目录。拒绝绝对路径、遍历、链接、特殊文件、Windows 保留名、非法字符、大小写及 Unicode 规范化名称冲突（包括隐含父目录）。本机准备不跟随链接，复制前后核对源文件元信息。保留空目录。另存为使用 create_new，不静默覆盖用户文件。

每次流式写入前检查磁盘，进程内写入预留量统一计算，保留 1 GiB 余量。缓存历史默认 10 条；当前剪贴板、原生文件引用、在途任务来源、另存为中的记录都计为引用。无引用 24 小时后才回收；另存为的用户文件不进入缓存回收目录。

## 验证入口

- `cargo test -p easycopy-client-core`：安全归档、名称检查、内存剪贴板等不触碰系统剪贴板的测试。
- `cargo test -p easycopy-client-core --test native_clipboard -- --ignored --test-threads=1`：受控 macOS/Windows 原生公开格式读写。需要手动决定执行。
- `cargo test -p easycopy-integration-tests`：真实本地 HTTPS/WSS 服务配合两个 MemoryClipboard 客户端。

Windows 安装、资源管理器/微信粘贴、不同 DPI 和多显示器悬浮行为仍需相应真实环境验收，编译与内存剪贴板集成测试不能替代这些检查。
