# EasyCopy 官网

地址：https://qmtdlt.github.io/EasyCopy/

## 内容与维护

源码位于 `site/`，使用原生 HTML、CSS 和少量外观切换 JavaScript，无构建依赖、外部字体、统计脚本或浏览器 API 请求。关闭 JavaScript 后，介绍、下载、导航和常见问题仍可使用；页面跟随系统深浅色，也可手动切换。

网站展示文本、图片、文件和目录同步、最近十条历史、传输提示、大文件上传确认、三步上手及常见问题。明确说明需自行部署中转服务、Windows 安装包未签名、当前无应用内自动更新。

- `site/assets/easycopy.svg`、`favicon.png`：复用桌面应用图标。
- `site/assets/history.png`：来自 `apps/desktop/tests/artifacts/history-fixture.png`，真实前端界面的模拟数据截图，页面已标明演示数据，不包含真实配对凭据。
- `site/assets/workspace.webp`：为官网生成的双机桌面场景示意图，以 WebP 保存，不代表实际硬件要求或应用界面。

本地预览：

```sh
python3 -m http.server 58448 --bind 127.0.0.1 --directory site
```

打开 http://127.0.0.1:58448/ 。

## 最新版下载

三个桌面按钮使用以下固定链接，网页无需跟随版本号更新，也不调用 GitHub API：

- https://github.com/qmtdlt/EasyCopy/releases/latest/download/EasyCopy_macos_arm64.dmg
- https://github.com/qmtdlt/EasyCopy/releases/latest/download/EasyCopy_macos_x64.dmg
- https://github.com/qmtdlt/EasyCopy/releases/latest/download/EasyCopy_windows_x64_setup.exe

桌面发布流程必须继续上传三个固定名称附件，并在完整验证后将桌面正式版设为 Latest。中转服务 Release 保持 `--latest=false`，避免桌面下载入口指向服务器版本。网站展示“最新正式版”而不写死桌面版本号。

中转服务入口目前明确链接 `relay-v0.1.0`，服务端升级后单独更新入口；不复用仓库 Latest。

## GitHub Pages 部署

工作流 `.github/workflows/pages.yml` 将且仅将 `site/` 上传到 GitHub Pages。推送 `main` 上的 `site/**` 或该工作流变更时自动部署，也支持手动执行。GitHub Pages 的发布源设为 GitHub Actions；使用 `github-pages` environment 和部署 job 专用的 `pages: write`、`id-token: write` 权限。不会触发桌面或中转服务构建。
